L858D Language Switcher · 世光 858D 语言切换
正式版：0.4.0

用途
将符合条件的 L-858D / L-858D-U 切换为中文、English 或日本語。
使用原固件已有的语言和字库，不刷固件，不改变地区或无线模块配置。
应用提供中英双语界面；应用界面语言与测光表语言相互独立。
这是独立开发的工具，不是世光官方软件。

安装与需要的条件
• macOS 13 或更新版本；同一个通用应用支持 Apple 芯片和 Intel Mac。
• 一根支持数据传输的 Micro-B USB 线，只连接一台开机的测光表。
• 固件明确为 17、18 或 19；设备报告的地区为 0000、0001、0002 或 0003。
• 当前设备语言为英文、日文或中文。
解压 Mac 应用包，将 L858D Language Switcher.app 放入“应用程序”文件夹后打开。
应用自包含；切换受支持固件的语言不需要 Python、Homebrew、REA、Xcode、
世光 Data Transfer Software（DTS）、额外驱动或固件文件。源码包用于开发者。
本工具目前仅支持 Mac，不提供 Windows 应用。

使用方法
1. 退出旧版语言工具、世光 DTS、固件更新器及其他连接测光表的程序。
2. 使用数据线连接一台测光表并开机，点击检测按钮。
3. 核对型号、固件、地区、当前语言及界面显示的验证范围。
4. 点击目标语言并保存。操作结束前保持供电和 USB 连接。
5. 收到保存确认后拔掉 USB，关机再开机，确认菜单语言；可重连后再次检测。
当前语言按钮停用，不会重复修改或保存。需要恢复日文或英文时，按同样流程
选择对应语言。切换应用界面为 English 不会修改测光表。

其他固件怎么办
本版本只允许明确的 17、18、19；不支持的版本会停止，不提供跳过检查选项。
较旧固件请先通过世光官方 Data Transfer Software 升级到 19，再使用本工具：
1. 退出本语言工具，从下方官网选择 L-858D，下载适用电脑的 DTS 并阅读官方指南。
2. 在 DTS 的 Update Setting（更新设置）中按官方步骤升级到 19；升级过程中
   保持连接和供电，完成后按原厂提示拔线、重启测光表。
3. 完全退出 DTS 和固件更新器，重新连接并打开本工具，检测到 19 后再切换语言。
已是 17、18 或 19 时，无需为了切换语言升级。语言工具不集成升级或降级，
压缩包不附带任何世光固件；本项目的研究降级过程不属于用户安装步骤。
DTS 有独立的系统要求，请以官方指南为准；本工具支持 macOS 13+ 不表示
官方 DTS 同样支持所有这些系统。若官网只提供本工具尚不支持的新版本，
或设备已新于 19，请保留检测结果、联系世光支持并等待工具适配，不自行降级。
官方软件下载：https://sekonic.com/downloads/
日本官方支持：https://www.sekonic.co.jp/product/support/

实际验证范围
所有硬件测试来自同一台日本地区（0002）设备。
• 17、19：中文切换、保存、读回及断开 USB 后重启保持中文均已验证。
• 18：英文写入、保存、读回和后续独立读取通过；原中文跨固件更新及重启
  保留已验证。18 的新中文/日文写入未实测，英文重启步骤未获逐项明确确认。
• 17：从 18 保留的英文经明确重启和读回通过，不等于执行过新的17英文写入。
• 19：日文和英文的保存读回通过，未确认它们各自的重启持久性。
地区 0000（美国 L-858D-U）、0001（其他已核验地区）、0003（默认中文地区）
只有固件静态分析和离线测试，尚无对应地区实机。三种语言均有原固件协议依据，
但不代表每个版本、语言方向、地区或硬件批次都已实测。详情见“兼容性与验证.txt”。

遇到问题
• 未检测到：检查开机、数据线和连接，尽量直接连接 Mac。
• 无法独占设备：退出其他测光表程序，再检测。
• 不支持的地区或语言：保留操作记录，不能跳过检查。
• 通信中断或状态不确定：停止重复点击。语言或设置可能已改变；等工具停止后
  拔线、关机重启，核对菜单，再重新连接检测。
• 分享操作记录前隐藏序列号。记录只保存在本机。

Mac 首次打开
本应用为本地签名（ad-hoc），未经过 Apple 公证；macOS 可能无法验证开发者。
确认下载来源和文件完整性后，先尝试打开，再到“系统设置”→“隐私与安全性”，
按系统提示选择“仍要打开”。若系统明确提示恶意软件或文件已损坏，请停止并核查。
无需关闭系统安全保护或删除下载文件的安全标记。
Apple 官方说明：https://support.apple.com/zh-cn/102445

保存和恢复
工具调用原厂设置保存功能，保存当前 SETT 设置块，包括语言；不是整机备份。
本工具不提供校准恢复或测光精度校准。恢复出厂设置可能恢复该地区的默认语言。
